# Speed RAW

Fast macOS photo culling application for RAW/JPEG wedding photography.

## Current controls
- 1–5: write XMP rating and advance
- 6–0: Red / Yellow / Green / Blue / Purple and advance
- Left/Right: navigation
- Filters: rating, threshold, selected, color and combined filters
- R: clear rating
- CR3 and common RAW/JPEG extensions are scanned

Target: macOS 14+, Apple Silicon.
